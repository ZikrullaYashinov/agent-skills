# 🌐 Universal AI Agent Init Prompt (Barcha AI Agentlar uchun)

> **Qanday ishlatiladi:** Yangi loyiha boshlaganingizda, qaysi AI agentda (Antigravity, Claude Code, Cursor yoki Codex) bo'lishingizdan qat'i nazar, quyidagi matnni nusxalab chatga tashlang. Agent o'zini qaysi tizimda ekanini o'zi aniqlab, Obsidian skillarini to'g'ri papkaga ulab oladi.

---

### 📋 Chatga nusxalab tashlanadigan matn:

```markdown
Sen mening markaziy Obsidian Skill bazamni ushbu loyihaga avtomatik bog'lab berishing (init qilishing) kerak:

- Manba papka: /Users/zikrulla/Desktop/obsidian/skills

Vazifang:
1. O'zing qaysi AI muhitida ishlayotganingni aniqla (Google Antigravity, Claude Code yoki Cursor/Codex):
   - Agar **Antigravity** bo'lsang: Loyihada `.agent/workflows/` papkasini och va manbadagi barcha `.md` fayllarni unga symlink (`ln -sf`) qil.
   - Agar **Claude Code** bo'lsang: Loyihada `.claude/commands/` papkasini och va manbadagi barcha `.md` fayllarni unga symlink (`ln -sf`) qil.
   - Agar **Cursor / Codex** bo'lsang: Loyihada `.cursor/rules/` papkasini och va manbadagi barcha `.md` fayllarni unga bog'la.
2. Sinxronizatsiyani amalga oshir va ushbu loyihada qaysi slash-komandalar (`/nomi`) foydalanishga tayyor bo'lganini jadval qilib ko'rsat.
```
